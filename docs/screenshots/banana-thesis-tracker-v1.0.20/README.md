# Android app screenshots · 1.0.20

These are unedited PNG captures from a USB-connected **realme RMX2151** running **Android 12** and Banana Thesis Tracker **1.0.20** (`versionCode 21`). The phone reported 1080 × 2400 pixels. Captures were made on **November 16, 2026** at approximately 6:08–6:10 PM (phone clock).

The app was updated in place from 1.0.18 using `adb install -r`. Each screen was captured with `adb shell screencap -p` and transferred with `adb pull`. Navigation and filter taps changed only the visible screen; no record was added, edited, or deleted for these captures. Counts and entries are a snapshot of the signed-in account's live data.
