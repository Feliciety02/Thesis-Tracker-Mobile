# Banana Thesis Tracker Android 1.0.20

The [signed APK](Banana-Thesis-Tracker-Android-1.0.20.apk) has package ID `com.feliciety02.thesistracker`, `versionCode 21`, and `versionName 1.0.20`. Its SHA-256 digest is recorded in [SHA256SUMS.txt](SHA256SUMS.txt).

This release uses the same signing certificate as the previous team release (certificate SHA-256: `a5da57b857aa2130ed3f93c7435dca6a661a29578b61e228b03d0edfcbe51988`). Install it over an existing team release to retain queued uploads and app data. Android cannot install it over a debug build signed with a different key.

The APK contains the Android app. Updates to the Google Sheet and Drive backend in `apps-script/WebApp.gs` require a separate Apps Script deployment.
